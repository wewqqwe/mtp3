# Лабораторная работа №3

Осетрова Алина Романовна, группа 221141, вариант 3, лабораторная №3

Тема: банковский счёт; Животное→Собака; класс для файлов; заказы (Товар, Корзина); мини-ORM

## Постановка

Объектная модель варианта 3: счёт с контролем остатка, наследование реплики, чтение и запись файла, корзина товаров и таблица поверх sqlite3. Вспомогательные правила вынесены в отдельные модули.

## Соглашения варианта

- Простые числа: все простые от 2 до 100 включительно; само число 100 простым не является.
- Список Фибоначчи и генератор начинаются с 0, 1.
- Границы диапазона случайных чисел включительные.
- Слова выделяются выражением `[0-9A-Za-zА-Яа-яЁё]+` и приводятся к нижнему регистру.
- Карринг: f(a)(b) == f(a, b).

## Состав

- `bank.py` — класс `Account`.
- `animals.py` — классы `Animal` и `Dog` (Животное→Собака).
- `filebox.py` — класс для файлов `FileBox`.
- `orders.py` — заказы (Товар, Корзина): классы `Product` и `Cart`.
- `orm.py` — мини-ORM, класс `Table`.
- `money`, `voices`, `cabinet`, `records` — вспомогательные модули.

## Запуск

```bash
python main.py
python -m pytest
```

Зависимость для проверок указана в `requirements-dev.txt`. Код лабораторной использует только стандартную библиотеку.
